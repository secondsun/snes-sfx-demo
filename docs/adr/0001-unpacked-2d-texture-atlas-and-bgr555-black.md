# Unpacked 1-Byte-Per-Texel 2D Texture Atlas and BGR555 $0001 Opaque Black

The Texture Atlas `.bin` format stores 16-color (4bpp) textures as unpacked 1-byte-per-texel values (`$00`–`$0F`) arranged in a 2D row-major power-of-two buffer (`16×16` to `256×256`), rather than planar 4bpp SNES tiles or packed 2-texels-per-byte nybbles. On the SuperFX (GSU), fetching one byte per texel via `R14` allows the inner scanline rasterizer loop to execute `getc; plot` directly without per-pixel bit-shifting or masking, and constraining the atlas width to a power of two reduces 2D row indexing (`(Y * ATLAS_WIDTH + X) + (v << ATLAS_STRIDE_SHIFT) + u`) to a single precomputed base offset plus bit-shift. In the companion 16-color BGR555 `.pal` binary, palette index `0` (`$0000`) is permanently reserved for transparency (`cmode` bit 0 = 0), and opaque black is clamped to `$0001` (`R=1, G=0, B=0`) so that transparent texels and opaque black colors remain unambiguous during import, quantization, and editing.
