# Non-Square Power-of-Two Textures, 8-Byte Texture Descriptors, and Unified Cached-Trap Rasterization

To support non-square architectural terrain elements (such as $32 \times 16$ parapet Edge Panels and $16 \times 32$ foliage cutout fins) without sacrificing the SuperFX 512-byte CACHE inner-loop throughput or introducing sub-pixel seams, `IsoEngine` adopts the following architectural decisions:

1. **Strict 1:1 World-Texel Scale for Non-Square Primitives**: All non-square Source Textures preserve a 1:1 ratio between world spatial dimensions and texture coordinates (e.g., $32 \times 16$ texels for a $1\text{h}$ half-block parapet spanning 32 units wide by 16 units high, and $16 \times 32$ texels for a half-cell foliage fin spanning 16 units wide by 32 units high). This maintains uniform pixel density across all surfaces without requiring runtime scaling multipliers or software divisions in scanline setup.
2. **Independent Power-of-Two Bitmasks & 16-Pixel Atlas Alignment**: Individual Source Textures support independent power-of-two dimensions $W, H \in \{16, 32, 64, 128, 256\}$. Coordinate wrapping is governed by independent bitmasks: $u_{\text{mask}} = W - 1$ and $v_{\text{mask}} = H - 1$. The Texture Atlas packer enforces a strict 16-pixel grid (`gridSize = 16`), ensuring that because cell dimensions ($32$) are integer multiples of 16, world-space coordinate offsets $(i \times 32, j \times 32)$ automatically wrap to zero at cell boundaries ($(i \times 32) \ \& \ 15 \equiv 0$) with zero coordinate drift.
3. **8-Byte `Texture Descriptor` with Link-Time Bank 4 Addressing**: Each entry in `TEXTURE_TABLE` is standardized as an 8-byte record composed of four 16-bit words: `rom_offset` (absolute 16-bit address in Bank 4), `u_mask`, `v_mask`, and `stride_shift` ($\log_2(\text{ATLAS\_WIDTH})$). The base address is pre-baked at link time using `.loword(textures_binary + <offset>)`, eliminating runtime addition instructions during trapezoid scanline setup.
4. **Unified CACHE-Resident Trapezoid Rasterization (`draw_cached_trap.i`)**: The legacy prototype triangle rasterizer (`drawTriangle.i` / `plot_texel`), which hardcoded 32x32 textures and per-scanline reciprocal division, is formally retired. All surfaces—including flat floors, sloped wedges, staircases, multi-step skirts, and non-square edge panels/fins—are compiled into Scanline Trapezoids (`cached_trap`) and rasterized exclusively through the 1-cycle CACHE-resident DDA inner loop.
